Vice Cover Studio turns any of your photos into an original GTA-style multi-panel cover — slanted comic panels, bold outlined caption lettering and a Vice City sunset, neon or noir grade — then exports it as a PNG in 1080×1080, 1080×1350 or 1920×1080. Everything runs offline in the browser; photos never leave your machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
